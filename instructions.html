Windows Security

Disable real-time protection and core isolation
1
Open Windows Security

Press Win + S, type Windows Security, and open it.

2
Virus & Threat Protection → Settings

Click Virus & Threat Protection → scroll down → click Manage Settings. Turn OFF these in order:

  • Tamper Protection (do this one first)
  • Real-Time Protection
3
Device Security → Core Isolation

Go back home → Device Security → Core Isolation Details → turn off everything shown.

🔧 Troubleshoot — Memory Integrity greyed out?

Open Command Prompt as Administrator and run these two commands one at a time:

CMD — Command 1
reg add HKLM\SYSTEM\CurrentControlSet\Control\CI\Config /v VulnerableDriverBlocklistEnable /t REG_DWORD /d 0 /f
CMD — Command 2
reg add "HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\HypervisorEnforcedCodeIntegrity" /v "Enabled" /t REG_DWORD /d 0 /f
⏸️
Don't restart yet
Run the commands and continue — you'll restart after D-Control in Step 2.
2

Download & Run D-Control

Keeps Defender off permanently across reboots
1
Download D-Control

👉 https://gofile.io/d/LHMqbjIC

2
Extract the ZIP

Right-click the downloaded file → Extract All → extract to your Desktop or anywhere easy.

3
Run the EXE

Open the extracted folder and run the .exe. If SmartScreen pops up: More Info → Run Anyway.

4
Click “Disable Windows Defender”

Hit that button inside D-Control.

5
Restart your computer

Now restart. After reboot, Defender stays off permanently until you re-enable it yourself.

Why We Do This

An honest breakdown — no malware, we promise
🔒
This software does not install any malware.
Here is exactly why each step is required, in plain language.
🛡️

Disabling Windows Defender

Our loader uses a low-level kernel driver that Defender flags the same way it flags any unsigned system driver. We need it off so the software isn't blocked before it even starts.

🔧

D-Control (Recommended)

Without D-Control, Defender re-enables itself on every restart. D-Control keeps it off so you don't have to redo Step 1 on exam day.

🧠

Core Isolation / HVCI

This helps our operations stay stealthy xD

Multi-Screenshot Mode NEW

For questions that are too long to fit in one screenshot
💡
When do you use this?
Some exam questions are very long — you need to scroll down to see all the answer choices. One screenshot won't capture everything. Multi-Screenshot lets you take 2–5 screenshots and send them all to the AI at the same time so it sees the full question.

📝 Step-by-step: How to use it

1
Scroll to the TOP of the question in Bluebook

Make sure the beginning of the question is visible on screen.

2
Press ; (semicolon) — do NOT press [ or ] yet

The overlay will say Buffered: 1 screenshot. This means it saved that screenshot but did not send it anywhere yet. You're just collecting them.

3
Scroll down to reveal more of the question, then press ; again

The overlay will say Buffered: 2 screenshots. Keep repeating this for each part of the question you need to capture. Maximum: 5 screenshots.

When you hit 5, the overlay says 5 max screenshots — that's the limit, stop pressing ;.

4
Once you've captured everything, press [ for Gemini or ] for GPT

This sends all your buffered screenshots at once to the AI. The AI sees every screenshot together and gives you one answer based on the full picture.

After sending, the buffer is cleared automatically — you're ready to start fresh for the next question.

⚠️
Important: pressing [ or ] WITHOUT using ; first works normally
If you did not press ; at all, pressing [ or ] just does the normal single-screenshot mode. Nothing changes for regular questions that fit in one screen. You only use ; when you need to scroll.
💡
Quick memory trick
; = save/buffer it   |   [ or ] = send them all
Think of ; like putting screenshots in a shopping cart, and [/] as hitting checkout.
📷 Multi-Screenshot Quick Reference
;
Buffer a screenshot — press once per screen section. Overlay counts: “Buffered: 1 screenshot”, “Buffered: 2 screenshots”, etc.
[ ]
Send all buffered screenshots — [ sends to Claude, ] sends to GPT. Buffer clears after sending.
⚠️
Limit: 5 screenshots maximum. Overlay shows “5 max screenshots” when you hit the cap. Just press [ or ] to send what you have.

After Exam — Restore Your Computer

Back to 100% normal in under 5 minutes
✅
Do this right after your exam ends
You're just re-enabling what you turned off. Your PC will be completely back to normal.
1
Open D-Control → “Enable Windows Defender”

If it says service couldn't start, restart your computer and try again — works after reboot.

2
Re-enable the driver blocklist and HVCI

Open Command Prompt as Administrator and run both commands:

CMD — Restore 1
reg add "HKLM\SYSTEM\CurrentControlSet\Control\CI\Config" /v "VulnerableDriverBlocklistEnable" /t REG_DWORD /d 1 /f
CMD — Restore 2
reg add "HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\HypervisorEnforcedCodeIntegrity" /v "Enabled" /t REG_DWORD /d 1 /f
3
Re-enable Virus & Threat Protection

Windows Security → Virus & Threat Protection → Manage Settings → turn everything back ON.

4
Re-enable Core Isolation

Windows Security → Device Security → Core Isolation Details → turn everything back ON.

5
Restart your computer

One final restart and your system is fully restored. You're done. 🎉
